Managing bush encroachment on a holistically managed rangeland in a semi-arid African savanna in partnership with Shangani Holistic, as part of the Oppenheimer Programme in African Landscape Systems (OPALS; https://opals-exeter.org/)

This repository contains data from vegetation surveys, R codes for processing, analysing and visualising data.

Contact Tapiwa Gumbo (tg488@exeter.ac.uk) and/or Andrew Cunliffe (a.cunliffe@exeter.ac.uk)

1. 'DATA' - contains the project data that was used for analysis. 
  
 a. 'Coordinates' - SHR coordinates used for analysis
 
 i. 'Coordinates_SHR.xlsx' - geode coordinates for SHR used in analysis.
 
 
 b. 'Harmonized Taxonomisation' - output from the taxonomic harmonisation for grasses and woody plants. 
 
 i. 'Harmonized_WPspp26' - output with the taxonomic harmonisation of woody plants.

 ii. 'Harmonized2026b_GRspp.csv' - output with the taxonomic harmonisation of grasses.
 
 
 c. 'March 2026' - contains data that was used in analysis.
 
 i. '2Grasses2426updated.csv' - data for 2024 and 2026 grasses survey, used for biomass calculations.
 
 ii. 'Grasses2426Updated1.csv' - data for 2024 and 2026 grass survey.
 

 d. 'WFO_Backbone' - this is a folder for WFO, used for the taxonomic harmonisation.
 
 e. 'GEODE_Subplot_area' -  shows the area for each subplot, calculated using Geode's precise coordinates. 

 f. 'WFO_Backbone.zip' - zip file with WFO data.
 
 g. 'chirps-v2.0.monthly' - file used for CHIRPS analysis
 

2. 'Scripts' contains the scripts that were used in analysis.

 a. 'old scripts' - contains old scripts that were used for generating some plots.

 b. '1.QAQC GRasses2026' - script for grass QAQC.
 
 c. '2.QAQC-Woody' - script for woody plants QAQC.

 d. '3.Taxonomic harmonisation' - script used for taxonomic harmonisation for grasses and woody plants.

 e. '4. Woody & Grasses Analysis' - script used for analysis and to generate plots for woody plants and grasses.
 
 f. '5. Simpsons diversity WP'- script used for Simpsons diversity index analysis for grasses and woody plants.
 
3. 'Plots' - contains the plots generated from analysis.

4. 'QUARTO_files' - contains output from quarto.
