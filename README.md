Managing bush encroachment on a holistically managed rangeland in a semi-arid savanna 

This repository contains preliminary data from initial vegetation surveys, R codes for processing, analysing and visualising data.

1. 'Data' contains the project data that has been used for analysis.  
a. DPM. - contains DPM heights and oven dried weight for grass samples collected at SHR in 2025
b.Fire - shows data of unburnt vegetation in each subplot
c. Grasses - conatains data for 2024 grass survey.
d. Woody size classes - data for 2024 woody plants survey.
e. Grasses25 - data for 2025 grass survey.
f. GrassesCombined - data for 2024 and 2025 grasses survey combined.
g. Woody_with_separate_columns25 - data for 2024 and 2025 woody plants survey.
h. WoodyPC - data for 2025 woody plants survey.

2. 'Scripts' contains the scripts used in analysis.

3. 'Plots' contains the plots generated from analysis.
