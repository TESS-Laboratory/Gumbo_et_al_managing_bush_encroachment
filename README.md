Managing bush encroachment on a holistically managed rangeland in a semi-arid savanna in partnership with Shangani Holistic. 

This repository contains preliminary data from vegetation surveys, R codes for processing, analysing and visualising data.

1. 'Data' contains the project data that has been used for analysis.
  
 a. 'DPM.csv' - contains DPM heights and oven dried weight for grass samples collected at SHR in 2025

 b. 'Fire.csv' - shows data of unburnt vegetation (2024) in each subplot

 c. 'Grasses.csv' - conatains data for 2024 grass survey.

 d. 'Woody_sizeclasses.csv' - data for 2024 woody plants survey.

 e. 'Grasses25' - data for 2025 grass survey.

 f. 'GrassesCombined.csv' - data for 2024 and 2025 grasses survey combined.

 g. 'Woody_with_separate_columns25.csv' - data for 2024 and 2025 woody plants survey.

 h. 'WoodyPC.csv' - data for 2025 woody plants survey.


2. 'Scripts' contains the scripts used in analysis.

3. 'Plots' contains the plots generated from analysis.
