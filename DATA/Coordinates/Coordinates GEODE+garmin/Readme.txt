README: Shangani bush management plots


This folder contains two coordinate datasets for the bush management experimental plots. The file Coordinates SHR.xlsx includes the initial plot locations recorded using a handheld Garmin GPS and provides approximate positions for reference purposes. The file geode_coordinates.csv contains high-precision coordinates collected using a Geode GNSS receiver after revisiting and accurately geolocating the plots and quadrats. For all subsequent spatial analyses, the Geode dataset should be used, as it supersedes the Garmin GPS coordinates in accuracy.
